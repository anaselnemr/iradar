iRadar architecture: weekly change monitoring for infineon.com

Web teamabout 10 users, browser on the intranet
HTTPS, sign-in
Infineon cloud (AWS eu-central-1), intranet only
iRadar server: one container (Docker), one instance
Web dashboardPython Flask: review queue, exports, reports
Capture enginePlaywright + headless Chromium, reads public pages
Schedulerweekly check (Sun 03:00), Friday review reminder
Comparisontext, documents, images, prices, page components
Storage: 50 GB disk at /app/dataembedded SQLite database + page snapshots and screenshots (3.3 GB today); no separate database server
Backupdaily disk snapshot
www.infineon.comabout 3,600 public pages, read once a week
Public community sitesReddit, GitHub, Hacker News, YouTube: public mentions for the sentiment view
outbound HTTPS via proxy, read-only
Internal SMTP relayweekly report + Friday reminder to the web team
